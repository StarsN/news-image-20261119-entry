One image that sums up the world news of Thursday 19 November 2026, built as a newspaper front page (full-day edition): GTA VI's record-breaking launch day — an estimated $2.36bn in sales — as the lead story, with five tankers ablaze in the Strait of Hormuz, the Shenzhen summit of the Chinese, US and Russian leaders ending in a peace declaration, the World Court's verdict that Myanmar committed genocide against the Rohingya, NASA's confirmation of Voyager 1 at one light-day from Earth and the record $190.4M Van Gogh sale, plus a ticker of the day's other headlines. The picture is drawn at build time by draw_entry.py (Pillow); the program at main.py is a standard-library-only copier that delivers the picture (entry.png, 1024x1024) to the output directory byte for byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
